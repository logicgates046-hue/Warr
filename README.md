# WAR — Which Are You In?

WAR is a mobile-first political preference platform.

Users can:

- Create an account
- Receive a unique WAR number
- Vote once for WANTAM or TUTAM
- Enter the candidature arena
- Browse presidential/deputy tickets
- Vote once for a candidature ticket
- View live results
- Optionally join their side's WhatsApp community

## Technology

- Next.js
- React
- Supabase
- Vercel
- GitHub

## Status

WAR is currently under development.
